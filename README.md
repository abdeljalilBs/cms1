# 🛍️ ShopHub E-Commerce Website

A simple, modern e-commerce website built with pure HTML, CSS, and JavaScript.

## 📁 Project Structure

ecommerce/ 
├── login/ # Login page 
├── home/ # Home page with featured products 
├── shop/ # Shop page with all products 
├── cart/ # Shopping cart page 
├── profile/ # User profile and order history 
└── README.md


## 🚀 How to Run

1. **Download or clone** this project to your computer

2. **Open the login page** in your browser:
   - Navigate to the `login` folder
   - Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge)
   - Or simply double-click the `index.html` file

3. **Login** with any email and password (no validation required)

4. **Start shopping!**

## ✨ Features

- **Login System**: Simple email/password login (stored in localStorage)
- **Home Page**: Welcome message and featured products
- **Shop Page**: Browse all available products
- **Shopping Cart**: Add items, view cart, calculate totals with tax
- **Profile Page**: View user info and order history
- **Order History**: Track all completed orders
- **Persistent Data**: Uses localStorage to save cart and orders
- **Responsive Design**: Works on desktop, tablet, and mobile

## 🎨 Design

- Clean, modern interface
- Consistent color scheme (purple gradient theme)
- Smooth hover transitions
- Emoji-based product images
- Mobile-responsive layout

## 🛠️ Technologies

- **HTML5**: Structure and content
- **CSS3**: Styling and animations
- **JavaScript (ES6)**: Functionality and interactivity
- **localStorage**: Data persistence

## 📝 Notes

- No backend required - runs entirely in the browser
- All data is stored locally in your browser
- Clearing browser data will reset the app
- Use any email/password combination to login
- Products are mock data stored in JavaScript arrays

## 📱 Browser Compatibility

Works in all modern browsers:
- Chrome/Edge (recommended)
- Firefox
- Safari
- Opera
